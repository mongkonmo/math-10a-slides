    §2.3 Equal Groups

    MATH 10A

    Equal Groups Problems

    Definition 2.3.2

    An Equal Groups problem involves a set of objects divided into groups in which each group has the same number of objects.

    Components: number of groups, group size, product (the total across all groups).

    number of groups×group size=product product÷number of groups=group size product÷group size=number of groups

    MATH 10A

    Which Unknown Names the Subtype?

    ProblemGivenUnknownSubtype
    Grandma's cookies3 groups, 6 in eachproductEqual Groups (Multiplication)
    Mr. Gomez's cupcakes20 in all, 4 groupsgroup sizeEqual Groups (Partitive Division)
    Coach Brown's baseballs72 in all, 8 in eachnumber of groupsEqual Groups (Quotative Division)

    Quotative division is also called measurement division: we use the given size of each group to measure the total number of objects and see how many groups there are.

    §2.3 Array

    MATH 10A

    Array Problems

    Definition 2.3.6

    An Array problem involves a set of objects arranged in a rectangular array.

    Components: number of rows, number of columns, product (the total number of objects).

    number of rows×number of columns=product product÷number of rows=number of columns product÷number of columns=number of rows

    §2.3 Array

    MATH 10A

    Why Does 5×4=4×5?

    A child reads Grandma's cookies as three groups of six, never six groups of three. The equal groups model is not symmetric. Arrays show children why the two products agree.

    Same chairs, rearranged: the total does not change, so 5×4=4×5.

    §2.3 Area

    MATH 10A

    Area Problems

    Definition 2.3.12

    An Area problem involves representing the area of a rectangle using multiplication or division.

    Rectangles only. Components: length, width, product (the area of the rectangle).

    length×width=area area÷length=width area÷width=length

    §2.3 Area

    MATH 10A

    Which Side Is the Length?

    A 3 inch by 5 inch rectangle: which side is the length?

    Either one. Length and width are interchangeable, so for Area problems the two division subtypes are too.

    Table 2.3.13 tells them apart by the given side. Length given: Partitive Division. Width given: Quotative Division.

    §2.3 Multiplicative Compare

    MATH 10A

    Multiplicative Compare Problems

    Definition 2.3.16

    A Multiplicative Compare problem involves a comparison between two quantities in which one quantity is described as a multiple of the other quantity.

    Components: smaller quantity, bigger quantity, scale factor (how many times larger).

    scale factor×smaller quantity=bigger quantity bigger quantity÷smaller quantity=scale factor bigger quantity÷scale factor=smaller quantity
